❓ FAQ

  • How is inter-agent overhead calculated? Overhead = avg messages per task × avg tokens per message. Added to total tokens per task.
  • Which topology uses least tokens? Pipeline typically uses fewest tokens because each agent only sees previous output, reducing context.
  • Can I set a monthly dollar budget? Yes. Select a model and enter monthly $ budget; the tool converts to token budget using model price.
