Verdict

The reorder rule

  1. Stable system prompt - written once, never templated. No dates, no counters, no session IDs.
  2. Tool schemas in a fixed order - a reordered tool list is a changed prefix.
  3. Large reference docs - specs and retrieved context that survive the whole session.
  4. Few-shot examples - frozen examples before live conversation.
  5. Conversation history - appended to, never rewritten mid-session.
  6. Dynamic user data and timestamps LAST - where they cannot invalidate anything above them.
