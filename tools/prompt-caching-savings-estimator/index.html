On claude-opus-5 the cache read rate is 5e-7 USD per token against a fresh input rate of 0.000005 USD per token, per the OpenRouter models API (https://openrouter.ai/api/v1/models). The tool below computes the dollar difference per request from those validated rates, in your browser, with the formula shown.

Formula and assumptions

Cached cost per request = cached tokens x cache read rate + cache write rate x cached tokens on the first request + fresh input tokens x input rate + output tokens x output rate. Uncached cost per request = (cached + fresh input tokens) x input rate + output tokens x output rate. Savings per request is the difference; total multiplies by the request count, amortizing the one-time cache write cost across all requests. Cache writes bill at the cache write rate on the first call only; this tool amortizes that cost over the number of requests you enter, so a low request count will overstate savings if the cache expires and rewrites often. Rates are per token, in USD.

This tool does not execute LLM calls. All computation happens locally in your browser.

Why the cache read rate moves the total

The cache read rate is the lever. For claude-sonnet-5 the cache read rate is 2e-7 USD per token versus an input rate of 0.000002 USD per token, both from the OpenRouter models API (https://openrouter.ai/api/v1/models). The estimator computes the exact per-request delta from those two rates rather than stating a fixed ratio, because the savings depend on your token mix and request count. The first request also pays the cache write rate, 0.0000025 USD per token on claude-sonnet-5, which the tool amortizes across your request count.

Keep the cached prefix stable. If your system prompt or retrieved context changes between calls, the cache misses and you pay the write rate again without earning the read discount. The estimator assumes a stable prefix, so treat its output as a ceiling when your prompts vary.

Common questions

Does caching help with short prompts

Usually not much. Savings scale with cached token volume times the gap between the input and cache read rates, so a few thousand cached tokens produce cents per thousand requests while a long stable system prompt with retrieved context produces the noticeable sums. Run your own counts through the estimator rather than trusting a rule of thumb.

What rate applies on the first call

The cache write rate. For claude-haiku-4-5 that is 0.00000125 USD per token, from the OpenRouter models API (https://openrouter.ai/api/v1/models). The estimator includes it once, amortized across the request count you enter.
