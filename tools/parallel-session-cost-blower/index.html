Where the multiplier hides

  • Git worktrees with N agents — one branch per agent looks tidy, but every worktree is a full-rate session re-reading the same large context.
  • Background subagents you forgot — fire-and-forget calls keep billing after the main session looks idle.
  • Retry storms under concurrency — parallel sessions hitting rate limits re-send full context on every retry.
  • Monitoring loops — an agent polling a dashboard on a timer bills while producing zero deliverables.
  • Orphaned tmux panes — the session you detached yesterday is still running its loop.
