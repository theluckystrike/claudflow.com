How the math works

Writes pay the 5-minute cache-write rate; reads pay roughly a tenth of that. The first request always writes. Invalidated requests rewrite the entire prefix, so the multiplier is the blend of read and write prices across your traffic.

What breaks the cache

  • Timestamp in system prompt — injecting a fresh clock value changes the prefix on every request.
  • Random nonce or request ID in the prefix — any per-request unique value before the cached content invalidates everything after it.
  • Unstable tool ordering — tool definitions that serialize in non-deterministic order shift the prefix between requests.
  • Per-request user data in the prefix — user IDs or retrieved documents inserted before the static context force a rewrite.
  • Router prepend — a routing layer that adds metadata before your prompt changes the prefix per route.
  • 5-minute TTL expiry — gaps longer than five minutes cool the cache; the next request pays a full write.

Frequently asked

How much does a cache miss cost?

On Anthropic pricing a 5-minute cache write costs 12.5x a cache read for Sonnet-class models ($2.50 vs $0.20 per million tokens). A 50k-token prefix costs $0.01 per request when cached and $0.125 per request when invalidated. Opus is worse: $5.00 per million to write, 25x the read price.

Why does my cached prompt still miss?

Anthropic prompt caches expire after 5 minutes of inactivity. Any prefix change also invalidates the cache: one new token at the start forces a rewrite of everything downstream, even if the rest is byte-identical.

Does this apply to Claude Code and agent frameworks?

Yes. Agent stacks routinely inject timestamps, session IDs, or freshly serialized tool lists into the system prompt. A framework that prepends a per-request trace ID silently disables caching for everything below it.

Where should dynamic content go?

After the static prefix. Put system prompt, tool definitions, and large stable context first; put timestamps, user data, and retrieved documents last. Sessions with a fixed prefix hold cache across turns; sessions that mutate it pay full price every turn.
