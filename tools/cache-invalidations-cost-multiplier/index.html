Verdict

What breaks the cache

  • Timestamp in system prompt — injecting a fresh clock value changes the prefix on every request.
  • Random nonce or request ID in the prefix — any per-request unique value before the cached content invalidates everything after it.
  • Unstable tool ordering — tool definitions that serialize in non-deterministic order shift the prefix between requests.
  • Per-request user data in the prefix — user IDs or retrieved documents inserted before the static context force a rewrite.
  • Router prepend — a routing layer that adds metadata before your prompt changes the prefix per route.
  • 5-minute TTL expiry — gaps longer than five minutes cool the cache; the next request pays a full write.
