How this is computed

Formula: tool_budget = window − system − conversation − answer, minus the safety margin, divided by the number of tool calls. 4 characters per token converts the per-call budget to a truncation length for MCP server responses. If a result would exceed its share, either truncate it server-side or summarize it in a follow-up call.
