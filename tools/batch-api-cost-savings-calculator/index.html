How the math works

Sync cost is requests times the per-request token cost at list price. Batch API bills eligible traffic at 50% of list price, so the mixed cost is the sync cost reduced in proportion to the batched share. Batch responses can take up to 24 hours, so only traffic that tolerates the delay should move.

Frequently asked

What is the Claude Batch API discount?

Anthropic's Message Batches API bills input and output tokens at 50% of the standard rate. The trade-off is latency: batched requests complete within 24 hours rather than streaming immediately.

Which traffic is a good fit for batch?

Backfills, evaluations, classification jobs, report generation, and any workflow where a result in a few hours is fine. Interactive chat and agent tool-use loops are not, because they need low latency.

Are the rates exact?

The calculator uses list prices per million tokens for each model shown, matching Anthropic published rates. Enter your own blended rates if you have custom pricing.
