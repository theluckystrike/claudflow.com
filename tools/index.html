Workflow Tools

Free browser-based tools for building, testing, and optimizing AI workflows. Design prompt chains, manage token budgets, and track costs.

Drag-and-drop workflow builder with JSON export. Chain AI prompts into visual flowcharts with input, condition, transform, and output blocks.

Context Window Optimizer

Token budget planner and chunking strategy tool. Optimize how you allocate tokens across system prompt, context, and response in your workflow.

System Prompt A/B Tester

Compare two system prompts side by side with response quality scoring. Test different prompt strategies to find what works best for your use case.

Token Cost Tracker

Claude API usage dashboard with budget alerts. Track token consumption, estimate monthly costs, and set spending thresholds for your workflows.
